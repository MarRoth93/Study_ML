In short, if you have a function of many variables so f(x1, x2, x3, ...) then the Jacobian is simply a vector where each entry is the partial derivative of f with respect to each one of those variables in turn. By convention, we write this as a row vector rather than a column vector, for reasons that will become clear later in the course.
