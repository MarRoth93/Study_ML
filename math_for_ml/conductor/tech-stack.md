# Tech Stack - Math for ML Study Repository

## Core Technologies
- **Python:** The primary programming language for all mathematical implementations.
- **Jupyter Notebooks:** The interactive environment used for combining documentation, LaTeX equations, and executable code.

## Libraries and Tools
- **NumPy:** Used for high-performance numerical operations, specifically for vector and matrix manipulations.
- **Matplotlib:** Used for creating static, animated, and interactive visualizations to provide geometric intuition for mathematical concepts.
